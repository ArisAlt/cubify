📦 Vial ZIP Downloaded — How to Compile

Follow these steps to build and flash your Vial firmware. Requires a working QMK build environment.

STEP 1 — Clone vial-qmk (once)
git clone https://github.com/vial-kb/vial-qmk.git
cd vial-qmk && make git-submodule
⚠️ Keep vial-qmk outside your existing qmk_firmware folder.
STEP 2 — Copy your keyboard into vial-qmk
cp -r custom_handwired/ vial-qmk/keyboards/handwired/
Extract the ZIP first. The folder goes under keyboards/handwired/.
STEP 3 — Verify the environment
cd vial-qmk && qmk doctor
The only expected warning is about the upstream remote. All else should be green.
STEP 4 — Compile
make handwired/custom_handwired:vial
Use make, not qmk compile — the latter defaults to QMK firmware, not Vial.
STEP 5 — Flash
make handwired/custom_handwired:vial:flash
Or flash the .uf2 / .hex file with QMK Toolbox. Put your board in bootloader mode first.
💡 After flashing: Open the Vial GUI, your keyboard should be auto-detected. Use Security → Unlock (hold top-left two keys for ~3s) before making changes.
